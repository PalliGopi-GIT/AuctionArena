DOCUMENTED — Count HTTP room actions, creation, joins, tickets, upgrades, DO requests, Directory calls and alarms. Count inbound application WebSocket messages at the documented 20:1 billing ratio; account separately for socket upgrade requests and time that objects are active. Outbound messages have no per-message DO request charge. Count indexed row mutations and alarm writes. Include cleanup operations in a reserved allowance. At a two-second heartbeat, 5,000 users alone would send approximately 150,000 application frames per minute or 7,500 equivalent inbound DO requests per minute. This omits all bids, pings, setup, archive and SQL operations. If the cumulative upper bound, existing usage, available quota or zero-cost guarantee cannot be established, keep the test blocked.
